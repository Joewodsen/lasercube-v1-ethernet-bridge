# Deutsche Originaldokumente

Diese beiden Dateien sind die Arbeitsdokumente, aus denen das Projekt
entstanden ist. Sie stehen hier unverändert, weil sie den Weg zeigen — nicht
nur das Ergebnis.

- **[plan.md](plan.md)** — der Entwurf, bevor eine Zeile Code geschrieben war:
  warum der Pi sich als Netzwerkgerät ausgeben soll statt zu dolmetschen, wie
  das Pufferproblem gelöst wird, und die Risiken vorab benannt.
- **[befunde.md](befunde.md)** — was beim Bauen tatsächlich passiert ist: die
  zwei echten Hürden (die stille Blockade durch macOS und die echte
  Authentifizierung), ein teurer eigener Fehler, und die Messwerte.

Die englische Zusammenfassung steht im [README](../../README.md), die
Protokollreferenz in [docs/protocol.md](../protocol.md).
